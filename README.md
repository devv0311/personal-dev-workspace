# Personal Developer Workspace

A developer's **persistent context layer** — moving from remembering *where everything is* to a system that understands *how everything connects*.

**Capture → Connect → Understand → Act**

## Status

Project kickoff. No product implementation yet. Technology stack, architecture, and product boundaries are intentionally undecided.

## Context

The authoritative project context is [`Claude_Project_Blueprint.md`](./Claude_Project_Blueprint.md).

## Branch Strategy

- `main` — stable branch; always in a working state. Milestones merge here via PR after explicit acceptance.
- `develop` — integration branch for accepted work in progress.
- `feature/*` / `milestone/*` — short-lived branches off `develop`.
