# T3.3-CORRECTION — visual & behavioural acceptance checklist

Supersedes `T3.2-agentic-command-center-checklist.md` where the two disagree
(that file records the accepted state of T3.2, including the `EMAIL — NOT
CONNECTED` module this pass replaced).

Verified 2026-09-01 against the running application (core + worker + assistant,
real PostgreSQL, live GitHub) at 2048×1400, 1140×860 and 390×844. Evidence:
`app/docs/screenshots/t3.3-correction/`.

## Identity

- [x] The header states the workspace **head** and the **current user** as two
      separate facts, and collapses to one line only when they are the same
      person (`YOU Dev · WORKSPACE HEAD`).
- [x] Switching principal changes "you" and leaves the head unchanged
      (verified as Dev, Sanchit and Shourya).
- [x] The members list marks the correct row as `you` after a switch.
- [x] Settings states signed-in name, principal id, role, workspace and head.
- [x] No demo principal appears anywhere in the running UI.
- [x] Headship grants no extra visibility: a member with no shares sees one node
      and no artifacts.

## Mode A — command view

- [x] The six static capability circles are gone: `0` matches for `.cr-badge`
      and `[data-cap]` in the live DOM.
- [x] The core still carries the DEVWORKSPACE identity and its real counts.
- [x] The perimeter carries real artifacts (14 at capture time: 10 delivered
      routine runs, 4 pull requests), each with a category tint, a name and a
      category word.
- [x] Hovering an artifact shows its **timestamp** and source.
- [x] Activating one opens a detail modal with its stable reference, category,
      produced instant, state, read state and the source's own fields.
- [x] `Open source` appears only when a real URL exists; `Open in Second Brain`
      only when a real object does.
- [x] Read state is per person: an artifact read by the head stayed unread for
      another member, and the readout recount is immediate.
- [x] The right-hand readout has a single writer and reports artifacts.

## Mode B — Second Brain

- [x] No ring-per-data-type annotation remains (no CAPABILITIES / INBOX /
      PROJECTS / CONTEXT rings).
- [x] Hub at the centre, four real skills on ring 1 with their effective
      configuration, one angular sector per real project on ring 2.
- [x] Context fans outward along its own project's ray; sector labels carry the
      real project name and real context count.
- [x] Sector Focus on hover, selection and keyboard focus.
- [x] Unrelated branches, their structure and their labels measure exactly
      `opacity: 0.15`; the focused branch and its genuinely related objects stay
      fully visible.
- [x] Focus is emphasis, not filtering — every node stays in the layout.
- [x] Nothing outside the map is dimmed.

## Attention Stack

- [x] The section is titled **Attention Stack**; no e-mail placeholder remains.
- [x] Category pills print a count only when the source proved it exact.
- [x] Each source states its own condition with a reason
      (`REPOSITORY · CONNECTED`, `MAIL · NOT CONFIGURED — No mail provider is
      configured for this deployment.`).
- [x] No fabricated PR, alert, task or e-mail row. The queue is genuinely clear
      because the repository has no open PR, failing run or open issue.
- [x] `Mail accounts` opens the settings surface.

- [x] The privacy statement is present and accurate.
