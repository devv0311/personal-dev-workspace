### Reconstruction summary
- **Header** — thin warm top rule; wordmark + real identity line
  (`principal · N proj · N ctx`) + a compact ⌕/⊹/ⓘ icon cluster.
- **Central field** — added a NON-DATA ambient layer inside `#viewport`: a
  restrained central bloom (tints to the focused Project's hue on selection),
  a two-shell faceted wireframe enclosure, three concentric orbital guides and
  a ~420-particle mass (deterministic seed, static). The real Workspace /
  Project / context nodes and their real edges are unchanged and remain the
  only semantic layer. Framing now fits the whole composition so the mass
  stays centred and dominant at every width.
- **Search** — a centred spotlight field (header ⌕ / `/`) that adds
  `body.searching`: rails, header, panels and atmosphere attenuate to ~16 %
  while matches stay lit in place; pick → `revealAndFocus` → inspector.
- **Right rail** — `Attention` keeps the reference's hero-numeral grammar and
  its `PREVIEW` tag (numeral now counts only the rows shown); `Skills` is the
  reference's compact runnable-command card deck over the four REAL actions
  (`/capture` + the P3.4 assistant `/ask` `/summarize` `/extract-tasks`), with
  the assistant's real `provider · model` on the card face (probed live,
  `offline` if unreachable — never a fabricated model/effort badge);
  `Activity` is the reference's schedule/timeline treatment populated only
  with real capture events, newest row accented, past rows dimmed.
- **Motion** — nothing continuous; ambient rotation is off; the only added
  transitions are the bloom tint and the search attenuation, both removed
  under `prefers-reduced-motion`.

### Known deviation
- The Context Inspector remains the P3.2 bottom slide-up (not the reference's
  top-left dock). It carries every reference inspector field — type, title,
  project, timestamps, metadata, and relationships with verb / direction /
  provenance / confidence — but a node low in the field can sit close to the
  panel's top edge. Converting to a top-left dock was out of scope for T3.1
  (it would disturb the accepted responsive model).
